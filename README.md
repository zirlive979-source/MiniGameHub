# MiniGame Hub V1
30 mini games dalam satu website.

## Menjalankan
Buka `index.html` di browser. Tidak membutuhkan server untuk versi dasar.

## Fitur
- 30 game playable
- Search & kategori
- Favorite
- High score per game
- LocalStorage
- Responsive mobile UI
- Tanpa login
- HTML/CSS/JavaScript vanilla

## Catatan
Beberapa game arcade menggunakan mekanik ringan yang dibuat agar project tetap kecil dan mudah dikembangkan.
